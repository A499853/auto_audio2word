# 百度直播自动讲解扩展验收清单

本清单区分本地模拟验证与需要登录后完成的真实工作台验收。请不要将模拟页面通过理解为百度线上页面已经验证通过。

## 交付物

- [ ] `release/baidu-live-assistant/manifest.json` 存在，文件完整。
- [ ] `release/baidu-live-assistant-v1.0.0.zip` 解压后可以找到同样的扩展目录。
- [ ] Chrome 开发者模式可以加载该目录，没有扩展脚本错误。
- [ ] Edge 开发人员模式可以加载该目录，没有扩展脚本错误。
- [ ] 不需要安装 Python、桌面服务或输入接口密钥。

## 本地模拟功能

- [ ] 72 个商品完整扫描，计划 `1-72` 可以解析。
- [ ] 150 个商品可以扫描和生成计划，不存在 100 个商品的固定上限。
- [ ] 分页列表能够采集跨页商品，执行时可以定位到对应页。
- [ ] 虚拟列表能够通过滚动采集，并在执行时重新定位目标。
- [ ] 计划 `1,3,5-8` 按指定顺序执行，非法计划显示明确错误。
- [ ] 默认间隔为 8 秒，点击后等待“取消讲解”状态确认。
- [ ] 已经处于讲解状态的目标不会被误点成“取消讲解”。
- [ ] 暂停后不再切换；继续后恢复；停止后不再点击。
- [ ] 循环开启时末件回到首件；关闭时执行一次后完成。
- [ ] 商品移除或点击确认失败时记录错误，连续失败达到阈值后暂停。
- [ ] 不误点“预览”“下架”“删除”。
- [ ] 计划设置保存、导入导出、面板折叠与位置操作正常。

## 真实百度工作台（需要用户登录）

- [ ] 登录 <https://cecom.baidu.com/liveB/login#/home>，进入测试直播间的“直播商品”。
- [ ] 扫描数量与后台显示数量一致。检查首件、中间件、末件的序号和名称。
- [ ] 若显示数量不完整，核对分页、滚动容器或高级选择器，重新扫描。
- [ ] 设置短计划，例如 `1-3`，先用 8 秒间隔测试一轮。
- [ ] 观察 1 → 2 → 3 顺序切换，目标按钮由“讲解商品”变为蓝色“取消讲解”，对应商品出现“讲解中”。
- [ ] 观察上一商品状态由工作台正常切换，没有同时操作错误商品。
- [ ] 点击暂停后至少等待两个设定间隔，确认没有新的商品切换；继续后恢复。
- [ ] 点击停止后至少等待两个设定间隔，确认没有新的点击。
- [ ] 以实际商品总量生成完整计划。72 件商品使用 `1-72`；不要额外添加不存在的编号。
- [ ] 验证跨页或滚动列表中的首件、中间件和末件。
- [ ] 新增、删除或调整商品顺序后，停止并重新扫描再执行。
- [ ] 刷新页面和重新打开浏览器后不会自动开跑，需要手动开始。
- [ ] Chrome、Edge 各完成一次以上实际操作确认。

## 已知边界

后台网页结构、登录状态、直播间权限、网络或平台操作限制都可能影响执行。扩展通过可见页面按钮操作，不绕过权限，不依赖未公开接口。未登录页面无法提供真实商品 DOM，因此百度线上页面的最终适配需在上述验收中确认；可使用高级选择器调整识别。
