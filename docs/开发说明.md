# 实现与维护

扩展为 Manifest V3，使用本地普通 JavaScript、CSS 和 PNG 图标，加载发布目录即可运行。没有生产依赖、构建框架、服务器、录音、屏幕识别或自动登录流程。

- `extension/lib/adapter.js`：读取商品编号、身份和名称；处理滚动与分页；点击前重新定位；只允许精确的“讲解商品”文字；点击后等待“取消讲解”。高级 CSS 选择器用于适配网页结构变化。
- `extension/lib/core.js`：解析序号计划、校验配置和控制调度。重复编号不会被当作不同商品，缺失计划项会阻止启动。连续三次失败暂停。使用 AbortSignal 和任务版本号屏蔽过期操作结果。
- `extension/content.js`、`panel.css`：Shadow DOM 浮动面板；计划与外观保存到 chrome.storage.local；仅用户点击开启后运行。
- 真实百度卡片优先使用 `[data-key][class*="product-card-container"]`，通过 `input[class*="index-input"].value` 读取当前序号；标题优先取 `product-title`，避开父节点中的 ID 标识。哈希后缀变化不影响这些语义选择器。
- 面板拖动使用 Pointer Events、5px 移动阈值和 pointer capture；自由位置持久化，ResizeObserver 与窗口 resize 事件保持面板在可视范围内。
- `extension/popup.*`：工具栏入口；连接页面或打开直播中控台；扩展安装后已有标签页可按需重新注入内容脚本。
- `extension/background.js`：初始化本地设置；不调度直播商品，也不承担常驻计时。

讲解间隔从上件状态确认后开始计时，跨页定位和网页响应时间会增加实际切换耗时。浏览器后台节流、冻结及系统休眠也会延长间隔。

页面已接收的点击无法撤回。适配器在同一文档内保留待确认请求，即使暂停、停止或重建设置，也先确认旧请求再允许新点击。原请求超时后阻止进一步点击，需重新扫描恢复。点击“立即下一件”时等待当前任务完成，避免重复点击。

扫码/密码登录和后台商品 DOM 不在未登录页面中。1.0.1 已使用用户保存的真实页面验证 14 件商品识别，并在脱敏的同结构页面测试讲解点击。最终线上点击响应须在实际直播工作台验收。扩展未依赖或虚构百度直播 SDK，也没有调用未公开接口。

修改源代码后运行 `npm test`、`npm run check` 和 `npm run build`，从 `release/baidu-live-assistant/` 重新加载扩展。发布 ZIP 含同目录文件和使用说明，不包含测试用账号、浏览器配置或开发依赖。
