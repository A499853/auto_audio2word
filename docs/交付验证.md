## 需要真实工作台验收

百度未登录页面没有商品列表，无法确认当前账号下的真实商品 DOM、直播间权限及平台响应。请按《验收清单》在有权限的测试直播间完成最终验收；如页面结构不同，可填写高级选择器。

普通 Chrome 发行版限制命令行加载扩展，自动化测试使用 Chrome 官方开发者调试加载接口；最终用户通过 `chrome://extensions/` 的开发者模式加载含 `manifest.json` 的目录，Edge 使用 `edge://extensions/`。测试脚本的调试启动参数只用于一次性的隔离测试，不是用户安装步骤。
